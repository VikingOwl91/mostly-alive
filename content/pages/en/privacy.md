### Privacy-First Architecture

Mostly Alive is designed according to the principle of strict data minimization. Reading our safety manual requires no user account, sets no tracking cookies, and transmits no biometric or personal telemetry.

### 1. Web Hosting & Infrastructure

This website is deployed via **Cloudflare Workers / Cloudflare Pages** (Cloudflare Inc., 101 Townsend St, San Francisco, CA 94107, USA).

When you access our web pages, Cloudflare processes standard technical server connection logs to deliver assets securely and defend against distributed denial-of-service (DDoS) attacks:

- IP address (anonymized/truncated where feasible)
- Date and timestamp of the request
- Requested URL and HTTP status code
- User-Agent and referring URL

Legal basis: Art. 6 (1) lit. f GDPR (legitimate interest in secure, reliable web delivery).

### 2. Cookies & Local Storage

- **Public Guide**: Uses **zero tracking cookies**. No consent banner is required because no advertising or tracking scripts exist on this website.
- **Client-Side Preferences**: The site uses local browser storage exclusively to remember user-selected UI options (such as language preference and emergency region filters).

### 3. Web Studio & GitHub Authentication

If you access the `/editor` studio, authentication is handled via GitHub OAuth. In this case, only your public GitHub username is transmitted to authenticate pull requests and commits.

### 4. Your Rights under GDPR

You have the statutory right to request access to (Art. 15 GDPR), rectification of (Art. 16 GDPR), or erasure of (Art. 17 GDPR) your personal data. For privacy inquiries, contact [contact@nachtigall.dev](mailto:contact@nachtigall.dev).
